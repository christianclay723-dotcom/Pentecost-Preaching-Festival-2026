🔥 Connect Firebase

This dashboard syncs live across every device that has the link — but first you need to paste in your Firebase project credentials. Follow the 4 steps below, then open this file in a text editor and replace the YOUR_* placeholders at the top.

1
Go to console.firebase.google.com and create a free project (no billing required).
2
Inside the project, click Firestore Database → Create database. Choose Start in test mode (you can lock it down later).
3
Click the </> Web icon on the project overview page to register a web app. Copy the firebaseConfig object it gives you.
4
Open this .html file in any text editor, find the FIREBASE_CONFIG block near the top, and paste in your values. Save, then host the file on GitHub Pages, Netlify, or Cloudflare Pages — all free.
